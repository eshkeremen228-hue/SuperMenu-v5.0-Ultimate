## Русский

Мультифункциональное контекстное меню и набор инструментов для автоматизации Windows, написанный на **AutoHotkey v2.0**. Утилита объединяет в себе быстрый запуск, мониторинг системы, работу с буфером обмена и кастомизацию интерфейса.

### 🚀 Основные возможности
* **Быстрый поиск и запуск (Win + Space):** Умная строка для открытия файлов, папок, сайтов или поиска в сети.
* **Расширенный буфер обмена (Win + Shift + V):** История на 30 элементов с возможностью закрепления (Pin) важных данных.
* **Монитор ресурсов (Win + Shift + R):** Компактный и стильный виджет со счетчиками ЦП и ОЗУ.
* **Экранная пипетка (Win + Shift + P):** Захват цвета под курсором в форматах HEX/RGB.
* **Быстрые заметки (Win + Shift + J):** Текстовый блокнот со статистикой слов/символов и автосохранением.
* **Таймер и Будильник:** Удобные утилиты со звуковыми оповещениями.
* **Drag & Drop кастомизация:** Добавление своих программ, папок или сайтов прямо перетаскиванием в окно.
* **Двуязычный интерфейс:** Полная поддержка RU и EN локализаций.

### 🎹 Горячие клавиши
* `Alt + Z` — Главное контекстное меню
* `Win + Space` — Быстрый поиск / Запуск
* `Win + Shift + P` — Пипетка цветов
* `Win + Shift + R` — Монитор ресурсов
* `Win + T` — Открыть Терминал
* `Win + Shift + A` — Поверх всех окон
* `Win + Shift + C` — Скопировать путь к файлу из Проводника
* `Win + Shift + K` — Убить активное окно
* `Win + Shift + H` — Показать/Скрыть скрытые файлы Windows
* `Win + Shift + Q` — Полный выход из приложения

## English

A multifunctional context menu and power-user toolkit for Windows automation, built with **AutoHotkey v2.0**. It combines quick launching, system monitoring, clipboard management, and UI customization.

### 🚀 Features
* **Quick Launcher (Win + Space):** Smart input bar to open files, folders, URLs, or search the web.
* **Advanced Clipboard (Win + Shift + V):** History log for up to 30 items with a pinning system.
* **Resource Monitor (Win + Shift + R):** Compact, modern widget showing live CPU and RAM usage.
* **Color Picker (Win + Shift + P):** Grab any pixel color from your screen in HEX and RGB formats.
* **Quick Notes (Win + Shift + J):** Lightweight scratchpad with real-time character/word counting.
* **Timer & Alarm Clock:** Built-in productivity alerts with system sounds.
* **Drag & Drop Customization:** Add your favorite apps, folders, or links by simply dropping them into the manager window.
* **Dual Language:** Full support for English and Russian interfaces.

### 🎹 Hotkeys
* `Alt + Z` — Open Main Menu
* `Win + Space` — Quick Search / Run
* `Win + Shift + P` — Screen Color Picker
* `Win + Shift + R` — Resource Monitor
* `Win + T` — Open Terminal (PowerShell/CMD)
* `Win + Shift + A` — Toggle Always on Top
* `Win + Shift + C` — Copy selected file path from Explorer
* `Win + Shift + K` — Kill active window/process
* `Win + Shift + H` — Toggle hidden files visibility
* `Win + Shift + Q` — Exit SuperMenu
